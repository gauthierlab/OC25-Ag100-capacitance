# Changes in `ag100_followup_2026-10-08.tar.gz` (relative to `ag100_s0_2026-09-29.tar.gz`)

Read `request_to_meta_followup_2026-10-08.md` first. This file lists what changed in the code and how each new
structure set was built and validated.

## Code

- **`s0/build_s0_structures.py`**
  - New `--matrix {s0,lc,sl,lr1}` (default `s0`), plus `--sl-dn`, `--sl-no-water`, `--prefix` and `--bulk-side`.
  - New state matrices: `build_lc_matrix`, `build_sl_matrix` and `build_lr1_matrix`. The counter-ion sets use the
    electrolyte labels `H2O`, `F_ci`, `Na_ci` and `Cs_ci`.
  - `build_bulk_state` accepts a fixed box side and a concentration (LR1).
  - Species order skips absent species.
  - The bulk packmol templates use the right cation.
  - The S0 output is unchanged: two S0 states were rebuilt and compared atom-by-atom with the 2026-09-29 files
    (max |Δr| = 0).
- **`s0/make_vasp_inputs.py`**: the electrolyte → cation map was extended (`F_ci` and `H2O` → none, `Na_ci` → Na,
  `Cs_ci` and `CsF_bulk` → Cs). The resulting POSCAR and POTCAR orders were checked on LC states: pure water →
  `Ag O H`; F⁻ only → `Ag O H F`; Cs⁺ only → `Ag O H Cs`. In each, the vacuum is ~19 Å after centring.
- No change to `run_md_oc25.py`, `analyze_md.py`, `analyze_potentiometer.py` (already guards ion-free cells) or the
  INCAR template.

Each set directory holds `manifest.json`, `state_list.txt` and one directory per state (`init.extxyz`, `POSCAR`,
`packmol.inp`). The python fallback packer takes ~2.5 min per n = 16 state. We built the sets in parallel chunks
with `--only`, which gives identical results because each state's seed depends only on its ID.

## State-ID convention for the counter-ion sets

`<SET>_n<n>_<ion>_dN<±k>_<start>_r<k>`, where:

- `<ion>` is `H2O` (pure water, ΔN = 0), `F` (ΔN > 0, F⁻ only), `Na` or `Cs` (ΔN < 0, cation only);
- `<start>` is `surface` (odd replicas: excess ions start within 3 Å of the film bottom), `far` (even replicas:
  ≥ 12 Å above the top Ag) or `random`.
